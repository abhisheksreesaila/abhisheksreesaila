# Abhishek Sreesaila

### Mission: build the best personal AI agents, running locally on hardware you already own.

Your machine, your data, your agents. I build with best-in-class tools, agent-native from day one, and every project below is a piece of that: the engine that runs the models, the tools that build the apps, and the apps the agents live in.

| Project | What it is |
| :--- | :--- |
| **[MXConsole](https://github.com/abhisheksreesaila/mxstudio)** | Local AI in one command. Any model, an OpenAI-compatible endpoint, on your own GPU. Built on Mojo and MAX. |
| **[MXFrame](https://github.com/abhisheksreesaila/mxframe)** | Modern GPU-native dataframes. Mojo kernels, one codebase for NVIDIA, AMD and Apple Silicon. |
| **MXApp** *(coming soon)* | A universal language for GUI development. |
| **[fh-saas](https://github.com/abhisheksreesaila/fh-saas)** | Modern FastHTML for SaaS apps. Login, billing and tenants in plain Python. |
| **[PersonalNote](https://github.com/abhisheksreesaila/personalnote)** | A best-in-class personal notebook, with a modern interface and real mind maps. |
| **[GitAway](https://github.com/abhisheksreesaila/travelos)** | Your travel story, on GitHub's model. Plan a getaway, share it, let friends fork it. |
| **[Abode](https://github.com/abhisheksreesaila/abode)** | One home for all your coding agents. A T3 Code fork with a VS Code-style agents window and local voice. |
